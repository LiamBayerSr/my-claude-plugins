Build a rubric for this 3rd-grade assignment: $ARGUMENTS

Use the `ca-grade3-standards` skill to tie each criterion to a standard code.

Provide:
1. **Teacher rubric** - a table with 3-4 criteria and four levels: 4 Exceeding, 3 Meeting, 2 Approaching, 1 Beginning. Describe what the work looks like at each level in observable terms. Level 3 should equal mastery of the standard, so do not make "meeting" sound like a stretch.
2. **Student checklist** - 3-5 "I can" statements with simple icons or checkboxes, written so an 8-year-old can self-check.
3. **One model example** at level 3, written at a real 3rd-grade level (not polished adult prose).

Keep criteria about the skill being taught. Handwriting neatness and effort should not lower a content score unless the assignment targets them.
