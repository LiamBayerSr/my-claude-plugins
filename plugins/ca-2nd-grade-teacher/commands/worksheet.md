Create a printable 2nd-grade practice worksheet for: $ARGUMENTS

Use the `ca-grade2-standards` skill to confirm the standard and the `second-grade-teaching` skill for age-appropriate design.

Requirements:
- Title, name/date line, and one-sentence kid-friendly directions per section.
- Default 8-10 items unless a number was given. Start easier and build up.
- Use names, foods, and settings that reflect diverse California communities. Avoid holiday or religious assumptions.
- For math: include at least one word problem and one "explain your thinking" item; leave room for drawings.
- For reading/phonics: use decodable, grade-appropriate words; keep passages short.
- Make three versions: **Support** (fewer items, visuals, frames or word bank), **On level**, and **Challenge** (extension items). Same skill, same look, so no student stands out.
- End with an answer key for each version.

Produce it as a clean document the teacher can print (offer a Word or PDF file if they want one). Keep layouts uncluttered with big writing lines.
