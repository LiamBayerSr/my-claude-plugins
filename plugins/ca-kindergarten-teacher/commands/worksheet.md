Create a printable kindergarten practice worksheet for: $ARGUMENTS

Use the `ca-kindergarten-standards` skill to confirm the standard and the "Designing student materials" section of the `kindergarten-teaching` skill for age-appropriate layout, directions, and item count.

If the teacher attached curriculum pages, make practice that complements them rather than copying them.

Requirements:
- Title, name/date line, and directions per section written as the design notes describe.
- Default to the item count in the design notes unless a number was given. Start easier and build up.
- Use names, foods, and settings that reflect diverse California communities. Avoid holiday or religious assumptions.
- For math: use real-world pictures to count, compare, or show addition and subtraction within 10; include one "show me with a drawing" item.
- For reading and language: focus on letters, sounds, rhyming, and a few high-frequency words; use pictures for every word students must read.
- Make three versions: **Support** (fewer items, visuals, frames or word bank), **On level**, and **Challenge** (extension items). Same skill, same look, so no student stands out.
- End with an answer key for each version.

Produce it as a clean document the teacher can print (offer a Word or PDF file if they want one).
